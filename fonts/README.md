# Fonts

The fonts Stencilator bundles, for typed text and for SVG drawings that name a font they
do not carry. The command line builds them in; a project file names a bundled font
without embedding it.

`NotoSans-Bold.ttf` is Noto Sans Bold 2.015 from the Noto Project, under the SIL Open
Font License 1.1 (`OFL.txt`).
