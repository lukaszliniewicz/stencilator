# Fonts

The fonts Stencilator builds in, for typed text and for SVG drawings that name a font
they do not carry. The command line and the web app include both; a project file names a
built-in font without embedding it. Letters a font lacks are taken from Noto Sans Bold.

- `NotoSans-Bold.ttf`: Noto Sans Bold 2.015 from the Noto Project, under the SIL Open Font
  License 1.1 (`OFL-NotoSans.txt`). The default.
- `AllertaStencil-Regular.ttf`: Allerta Stencil 1.02 by Matt McInerney, from the Google
  Fonts repository, under the SIL Open Font License 1.1 with the Reserved Font Name
  Allerta (`OFL-AllertaStencil.txt`). A stencil font: its letters have bridges drawn in,
  so their middles do not fall out of a plate. Included unmodified.
